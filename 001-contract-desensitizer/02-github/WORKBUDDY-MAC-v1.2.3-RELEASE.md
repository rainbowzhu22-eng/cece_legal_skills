# WorkBuddy Mac v1.2.3 发布说明

本次发布仅提供 **macOS WorkBuddy 安装包**。Windows v1.2.3 仍在实机验收中，不属于本次 Release；扫描型 PDF 的 OCR、页面框选和黑条遮盖留待下一功能版本。

## 功能

- 本地识别并替换文字型 DOCX、PDF、TXT、MD 中的敏感信息；上传后可逐项取消或手工补录原文与别名。
- 诉讼材料发给外部顾问或 AI 审阅时，可用 DOCX 专用外发模式生成干净副本；映射文件单独下载和保管。
- 同一主体在全文使用一致编号；支持用独立的 `mapping.json` 还原已支持的文字替换。
- 本机历史记录可在服务重启后查看、下载和删除。

## 安装

1. 下载并解压 Mac ZIP；打开其中的 `WorkBuddy安装说明.md`。
2. 请 Mac 版 WorkBuddy 按说明运行一次 `bash install_macos.sh`。首次安装 Python 依赖需要联网。
3. 安装后从桌面打开“合同脱敏（WorkBuddy）.app”，在浏览器中复核和导出。

## 使用边界

- 扫描件、缺少可靠文字层的 PDF 会停止处理；本版不会在原扫描页上涂黑或清除图像里的签章、二维码。
- 外发干净副本目前只支持 DOCX。导出前请人工核对全文；图片、文本框、修订、隐藏文字等无法可靠清理的内容会阻断外发模式。
- 映射文件包含原文，不要随脱敏文书外发。已导出的文书不会因后续增加规则而自动更新。
- 安装包只含文本使用说明；旧图文 PDF 截图未完成公开核对，未放入本包。
- 本次用虚构文字型文书完成回归、浏览器流程和逐段还原核对；尚未对真实文字型法律文书逐处核对漏识别与误识别。外发前必须由使用者人工复核。

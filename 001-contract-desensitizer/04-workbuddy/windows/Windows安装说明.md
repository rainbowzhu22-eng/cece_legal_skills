# 合同脱敏工具 · Windows 安装说明

本目录是「合同脱敏（WorkBuddy）」**v1.2.3 Windows 候选版**。与同版 Mac 包使用相同的识别、复核与导出代码。安装前请注意：当前候选版尚未在 Windows WorkBuddy 实机完成验收。

> **隐私承诺**：服务仅监听 `127.0.0.1:18800`，完全离线，文书全程在本机处理，不上传任何云端。

---

## 一、目录内容

| 文件 | 说明 |
|------|------|
| `install_windows.bat` | 双击它即可安装（薄包装，自动寻找 Python） |
| `install_windows.py` | 真正的安装逻辑：部署技能 + 版本守卫 + 建 venv + 装依赖 + 自检 + 生成桌面入口 |
| `contract-desensitizer-offline/` | 脱敏技能本体（识别引擎 + 改写引擎 + Web 服务） |
| `停止合同脱敏服务.bat` | 关闭后台服务用（可复制到桌面） |
| `LICENSE` | 许可 |
| `README.md` | 本仓库说明（含修订历史与打包方法） |
| `REVISIONS.md` / `revisions.json` | 修订记录（改了什么、为什么改），供人或 Agent 阅读 |
| `reference/mac-originals/` | 原始 Mac 包里的文件，仅作「改动前原样」对照，不参与 Windows 运行 |

---

## 二、安装步骤

1. 解压本目录。
2. **双击 `install_windows.bat`**。
   - 首次运行会联网安装依赖（python-docx / pdfplumber / pypdf / reportlab / pypdfium2 / Pillow），约 1–2 分钟。
   - 安装器会自动寻找 Python：优先 WorkBuddy 受管 Python，否则系统 3.9+。
3. 安装完成后，桌面自动生成 **「合同脱敏（WorkBuddy）.bat」**。
4. 以后**双击桌面那个 .bat** 即可启动本地服务并自动打开浏览器到 `http://127.0.0.1:18800/`。

---

## 三、日常使用

- **启动**：双击桌面「合同脱敏（WorkBuddy）.bat」。
- **使用**：浏览器打开后上传合同 → 进入左右对比 → 勾选要脱敏的字段 → 应用并下载 `_脱敏.docx` 与 `mapping.json`（用于一键还原）。
- **停止**：网页右上角「退出」，或双击「停止合同脱敏服务.bat」。停止脚本只请求本工具服务退出，不会按端口结束其他程序。

> 说明：服务进程已做「脱离控制台」处理，关闭启动窗口不会让服务掉线（这是相对原版的修复，见 `REVISIONS.md`）。

## 四、给同事的 Agent 的说明

如果你（Agent）需要理解「这一版相对原 Mac 包改了什么、为什么改」，请阅读：

- `revisions.json` —— 机器可读清单，逐条列出修订、文件、根因、方案、验证证据；
- `REVISIONS.md` —— 同一内容的人类可读版本；
- `git log` / `git diff` —— 本仓库用三段提交记录全过程：
  1. `baseline`：原始 Mac 包；
  2. `Windows 适配`：新增安装器与说明；
  3. `修复 start.py`：进程脱离修复。

## 五、注意事项

- 自动识别仍可能漏项，外发前请人工核对全文。扫描件与缺少可靠文字层的混合 PDF 在 v1.2.3 中会阻断并提示本地 OCR；OCR、手工框选与黑条导出属于下一功能版。
- 「外发审阅模式」仅完成合成数据定向测试，完整安全与全量回归仍待验证。
- 依赖安装需要联网一次；运行期无需联网。
